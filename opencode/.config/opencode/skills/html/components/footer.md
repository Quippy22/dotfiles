# Purpose

Provides a clean concluding section with copyright, links, and relevant contact info.

# Visual Goals

A simple horizontal footer with muted text, centered or aligned with the main container.

# HTML

<footer class="mt-20 py-10 border-t border-slate-800 text-center">
  <p class="text-slate-500 text-sm">
    &copy; 2026 Company Name. All rights reserved.
  </p>
  <div class="mt-4 flex justify-center gap-6">
    <a href="#" class="text-slate-400 hover:text-slate-100 text-sm transition-colors">Privacy</a>
    <a href="#" class="text-slate-400 hover:text-slate-100 text-sm transition-colors">Terms</a>
    <a href="#" class="text-slate-400 hover:text-slate-100 text-sm transition-colors">Contact</a>
  </div>
</footer>

# Tailwind Notes

Centered text with subtle top border and muted colors.

# Composition

Typically placed at the very bottom of the main report container.

# Responsive Behavior

Full-width footer, centers content at all screen sizes.
